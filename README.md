## 🧮 Comprehensive Score Fusion Matrix

The system maps credibility using a weighted mathematical verification formula. If an image asset is absent, the system gracefully degrades to a text-only evaluation pipeline.

$$\text{Text Fake Risk } (T_r) = \text{Transformer Probability} \times 100$$
$$\text{Image Manipulation Risk } (I_r) = \text{ELA Compression Variance Score}$$
$$\text{Final Combined Risk } (R_f) = (0.7 \times T_r) + (0.3 \times I_r)$$
$$\text{Comprehensive Credibility Score} = 100 - R_f$$

### 📊 Verdict Decision Boundaries
* **$R_f \ge 95$**: `⚠️ LIKELY FAKE` — High-confidence systemic anomalies detected across both vectors.
* **$R_f \le 40$**: `✅ LIKELY REAL` — Validated context with zero structural manipulation signatures.
* **$40 < R_f < 95$**: `🔍 UNCERTAIN` — Divergent signals requiring secondary manual verification.

## 🌐 Live URL Ingestion & Parsing Mechanics

The `article_url_extractor` engine converts raw URLs into normalized data structures via a 4-tier pipeline:
1. **Metadata Parsing:** Maps Document Object Model (DOM) headers (`og:image`, `twitter:image`, schema headers).
2. **Heuristic Sanitization:** Structural regex passes strip script injections, navigation wrappers, and layout noise.
3. **Visual Extraction:** Identifies and ranks the primary image based on structural page density coordinates.
4. **Fallback Interface:** Standardizes on a user paste-buffer interface if automated scripts encounter strict anti-bot measures.

### 🛡️ Access Control & Troubleshooting
If live calls return `HTTP 401` or `HTTP 403`, the targeted server is employing strict CAPTCHA walls or access control lists (e.g., Reuters, paid subscription firewalls). The platform purposefully respects network boundaries and does not attempt credential evasion; users should copy the textual body content directly into the manual verification window.
